## 获取渠道说明

- **CiA iCC 论文(#1–#7)**:全部免费,已提供本地 PDF(见各条目页"下载本地 PDF"),也可从 CiA 官网 [ICC 页面](https://www.can-cia.org/services/conferences/the-international-can-conference-icc) 按届次浏览全部论文。
- **IEEE 论文(#8–#14)**:通过 [IEEEXplore](https://ieeexplore.ieee.org) 按 DOI 访问,建议使用所在公司/高校的 IEEE 机构订阅账号;单篇可在 IEEEXplore 付费购买;作者自存版本可能存在于 ResearchGate、机构库。
- **SAE 论文(#15)**:通过 [SAE Mobilus](https://saemobilus.sae.org) 按 DOI 或 SAE 编号 2017-01-0023 检索购买。
- 不建议使用 Sci-Hub 等非授权渠道获取付费论文,请优先机构账号或购买。
