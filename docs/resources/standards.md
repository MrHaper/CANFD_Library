> 📖 **标准全文查阅**:本站已收录免费公开标准的全文(如 [Bosch CAN FD Specification v1.0](standards-text/bosch-canfd-spec-full.md)),入口见[标准查阅](standards-text/index.md);付费标准(ISO / IEC / SAE)全文收录需授权,授权前仅提供本页索引与官方获取渠道。

> 标准规范是 CAN FD 学习的权威源头:ISO 11898 系列定义协议与物理层,ISO 16845 规定一致性测试,CiA 601/140 提供实现指南与勘误,Bosch 规范是协议原稿,SAE J2284-4 与 IEC 62228-3 分别覆盖整车应用与 EMC 评估。按优先级排序,必读 ★★★ 的三份资料应最先入手,推荐 ★★☆ 支撑设计流程,选读 ★☆☆ 按需查阅。已撤销的版本页内均有警示,请以现行版为准。
