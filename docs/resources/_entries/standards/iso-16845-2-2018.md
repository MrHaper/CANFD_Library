## 是什么
ISO 16845-2:2018 规定 CAN 一致性测试计划的第二部分:针对 ISO 11898-2:2016 高速介质访问单元(HS-MAU)的静态与动态测试,覆盖对称性、位时序、环路延迟等。

## 为什么值得读
- **模拟IC 工程师**:收发器芯片一致性测试的直接依据,流片后的表征与第三方认证(如 CiA 组织的 SIC 收发器 plugfest)测试项目均源于此。
- **嵌入式开发工程师**:了解收发器级验证内容,便于系统联调时解读测试报告。
- **学生**:看"物理层收发器如何被测试",是模拟与测试交叉领域的好教材。

## 核心内容要点
- 针对 ISO 11898-2:2016 HS-MAU 的静态/动态测试(Tx/Rx 延迟对称性、位时序、环路延迟)。
- 与 ISO 16845-1 配套覆盖协议与物理两端。
- 修订草案 ISO/DIS 16845-2(编号 90695)针对 ISO 11898-2:2024/2026 制定中。

## 怎么读
设计阶段即阅读 Part 2 测试项,为芯片预留测试模式与对称性校准接口;与 ISO 11898-2:2024 的参数条款对照使用。
