    ISO 11898-1:2015 已被 ISO 11898-1:2024 取代,ISO 官网不再展示该版页面。历史参考价值为主,新设计请以 2024 版为准。

## 是什么
ISO 11898-1:2015 是 CAN FD 协议首次国际标准化的版本,规定 CAN 数据链路层(DLL)与物理编码子层(PCS),是 ISO 11898-1:2024 的前一版。

## 为什么值得读
- **模拟IC 工程师**:理解 CAN FD 帧格式与 BRS 时序约束最初如何被写入国际标准,以及数据链路层约束如何转化为收发器延迟对称性需求。
- **嵌入式开发工程师**:了解经典 CAN 控制器如何扩展支持 EDL/BRS/ESI 等位,便于配置控制器寄存器与驱动。
- **学生**:作为 CAN FD 协议正式入标的历史节点,与 Bosch 原始规范对照可看清协议演进。

## 核心内容要点
- 定义 CAN 数据链路层与物理编码子层,首次标准化 CAN FD 帧(EDL/BRS/ESI 位、17/21 位 CRC、固定填充位)。
- 位定时、误差处理、协议控制器行为等协议机制的正式定义。
- 已被 ISO 11898-1:2024 取代(2024 版新增 CAN XL)。

## 怎么读
先读 Bosch CAN FD Specification v1.0(协议原型),再对照 ISO 11898-1:2024 看标准化后的差异。历史版本不必精读,重点理解其与现行版的继承关系。
