## 是什么
CiA 1301 是 CANopen FD(基于 CAN FD 帧的高层协议)的应用层与通信规范,含 CANopen FD 位定时表(仲裁/数据相位速率组合)。

## 为什么值得读
- **模拟IC 工程师**:属协议栈/HLS 层面,与收发器模拟设计关联弱;但对"收发器+控制器+协议栈"系统验证有间接意义。
- **嵌入式开发工程师**:CANopen FD 应用开发的直接依据。

## 核心内容要点
- CANopen FD 应用层与通信规范。
- CANopen FD 位定时表(仲裁/数据相位速率组合)。
- CANopen FD 一致性认证(CiA 测试中心)的强制项依据。

## 怎么读
嵌入式工程师按需精读应用层章节;模拟IC 工程师了解即可,不必深入。
