## 是什么
IEC 62228-3:2019 规定 CAN 收发器集成电路的 EMC 评估方法,包括传导发射(150 kHz–1 GHz)与射频抗扰度的测试板规范、测试条件与限值判断,是 CISPR 25 在收发器芯片层面落地的测试标准。

## 为什么值得读
- **模拟IC 工程师**:收发器 EMC 表征与车规认证的直接依据,设计阶段就应把测试板(去耦、共模扼流圈)考虑进评估方案。
- **嵌入式开发工程师**:了解整车 EMC 对网络设计的影响。
- **学生**:认识芯片级 EMC 测试方法。

## 核心内容要点
- 传导发射(150 kHz–1 GHz)与射频抗扰度评估方法。
- 测试板规范、测试条件与限值判断。
- 与 ISO 11898-2:2024 的 EMC 条款配套使用。

## 怎么读
在 EMC 表征阶段配合 ISO 11898-2:2024 阅读;设计早期即规划测试板方案。
