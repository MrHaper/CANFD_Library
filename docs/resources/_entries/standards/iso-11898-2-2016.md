!!! warning "已撤销"
    ISO 11898-2:2016 已被 ISO 11898-2:2024(及 ISO 11898-2:2026)取代,ISO 官网已下架。存量非 SIC 收发器设计仍以其参数为参考。

## 是什么
ISO 11898-2:2016 规定 CAN 高速物理介质连接(PMA)子层,首次将 CAN FD 收发器纳入 ISO 标准,并合并了原 ISO 11898-5(低功耗模式)与 ISO 11898-6(选择性唤醒)。

## 为什么值得读
- **模拟IC 工程师**:存量 CAN FD 收发器(非 SIC)的延迟对称性参数与测试定义来源于此,与 2024 版对比可清晰看出 SIC 新增的信号改进要求。
- **嵌入式开发工程师**:理解 CAN FD 收发器相比经典 CAN 收发器的延迟对称性差异。

## 核心内容要点
- 高速 PMA 子层,含 CAN FD 收发器要求(更严格的 Tx/Rx 延迟对称性以支持 >1 Mbit/s 数据相位)。
- 合并 ISO 11898-5/-6:低功耗模式与选择性唤醒。
- ISO 16845-2:2018 一致性测试即针对此版。

## 怎么读
若非存量设计兼容需求,建议直接读 ISO 11898-2:2024;如需对比,可先读 2016 版收发器条款,再逐段对照 2024 版新增的 SIC 内容。
