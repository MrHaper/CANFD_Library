## 是什么
ISO 11898-1:2024 是 CAN 数据链路层(DLL)与物理编码子层(PCS)的现行国际标准,覆盖 Classical CAN、CAN FD 以及 2024 版新增的 CAN XL(数据字段最大 2048 字节、AUI/PWM 等)。

## 为什么值得读
- **模拟IC 工程师**:数据链路层的 BRS 时序约束(相位裕度、位不对称)直接转化为收发器传播延迟对称性要求,是理解 TDC 需求的上游依据。
- **嵌入式开发工程师**:控制器侧的帧格式、CRC、位填充、错误处理均由本标准定义,驱动与配置据此撰写。

## 核心内容要点
- 规定 CAN DLL 与 PCS,覆盖 Classical CAN、CAN FD 与 CAN XL。
- CAN FD 的 EDL/BRS/ESI 位、17/21 位 CRC 与固定填充位定义。
- CAN XL 数据字段最大 2048 字节,引入 AUI/PWM 物理信令。
- BRS 位速率切换的时序约束(相位裕度、位不对称)是收发器设计的上游输入。

## 怎么读
建议先通读帧格式与位定时章节,再结合 ISO 11898-2:2024 的物理层条款对照阅读;嵌入式工程师可配合控制器数据手册的 CAN FD 寄存器映射。
