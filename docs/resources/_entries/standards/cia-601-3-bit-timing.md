## 是什么
CiA 601-3 是 CAN FD 节点与系统设计系列的技术报告,提供系统设计建议与 CAN FD 位定时配置/评估工具,用于相位裕度、位不对称计算。

## 为什么值得读
- **模拟IC 工程师**:位定时裕量分析工具与收发器延迟对称性预算直接相关。
- **嵌入式开发工程师**:系统设计与位定时配置的实操参考,配合采样点设置。
- **学生**:免费资料,学习"如何算位定时裕量"。

## 核心内容要点
- CAN FD 系统设计建议。
- 位定时配置与评估工具(相位裕度、位不对称计算)。

## 怎么读
与 601-1 配套阅读,结合示波器实测验证位定时裕量。
