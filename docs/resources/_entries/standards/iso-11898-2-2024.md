## 是什么
ISO 11898-2:2024 是 CAN 高速物理介质连接(PMA)子层的现行国际标准,规定全部 CAN HS-PMA 选项:经典 HS、CAN FD(带低功耗/选择性唤醒)、CAN SIC(signal improvement capability)与 CAN SIC XL。SIC 部分是 CAN FD SIC 收发器物理层设计的"金标准"参数来源;ISO 官网上现有更新版 ISO 11898-2:2026。

## 为什么值得读
- **模拟IC 工程师**:直接决定 SIC 收发器的共模/差分输出、上升/下降沿整形、回波损耗、振铃抑制电路与 EMC 特性,流片后的一致性认证也以它为准绳,是收发器设计的第一必读。
- **嵌入式开发工程师**:理解 SIC 收发器的振铃抑制与网络拓扑约束,便于评估车载网络的信号完整性与布线。

## 核心内容要点
- 覆盖经典 HS、CAN FD、CAN SIC 与 CAN SIC XL 全部 HS-PMA 选项。
- SIC 新增差分与共模振铃抑制要求(尤其 dominant→recessive 转换)与动态参数(振铃抑制窗口)。
- 相关 EMC 测试条款与 IEC 62228-3 配套使用。
- CiA 已就标准中图表不一致提出勘误(CiA 140),阅读时应配合索取。

## 怎么读
建议按"经典 HS → CAN FD → CAN SIC → SIC XL"顺序通读,重点精读 SIC 条款;同时向 CiA 办公室索取 CiA 140 勘误,配合阅读避免按错误图表演算参数。可与 Bosch 规范、CiA 601-1 的延迟对称性数值交叉印证。
