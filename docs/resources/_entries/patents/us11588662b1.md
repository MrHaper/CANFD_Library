## 是什么
NXP 于 2023 年公开的面向 CAN FD 与下一代 CAN XL 共存的收发器专利。CAN FD 显性→隐性过渡后总线反射可能被误判为 CAN XL 的差分电平方案,专利通过 "out-of-bounds(OOB)逻辑 + 武装状态机"对总线差分电压做超范围判别,仅在确认 CAN XL 电平后才向 RXD 输出相应信令,从而避免振铃反射在 CAN FD 通信期间造成毛刺。

## 为什么值得读
- **模拟IC 工程师**:接收器不仅要正确解调本协议电平,还要"认识并容忍"更高速度协议的电压摆幅;阈值窗口、消隐时间和状态机是接收器数字-模拟协同设计的范例。
- **嵌入式开发工程师**:理解 CAN FD 与 CAN XL 混网时收发器如何判别协议电平。
- **学生**:免费公开 PDF,可看到协议演进对模拟前端提出的新要求。

## 核心内容要点
- **解决的问题**:CAN FD 显性→隐性过渡后总线反射可能被误判为 CAN XL 的差分电平,在 CAN FD 通信期间造成毛刺。
- **技术方案**:OOB(超范围)逻辑 + 武装状态机,对总线差分电压做超范围判别,仅在确认 CAN XL 电平后才向 RXD 输出相应信令。
- **设计启示**:阈值窗口、消隐时间与状态机是接收器数字-模拟协同设计的关键。

## 怎么读
先读问题背景(CAN FD 振铃反射 vs CAN XL 电平判别),再读 OOB 逻辑与武装状态机的工作流程。PDF 免费公开,可直接下载本地阅读。
