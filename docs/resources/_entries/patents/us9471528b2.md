## 是什么
NXP 于 2016 年公开的一件完整 CAN 收发器架构专利,覆盖 CAN 总线接口、TXD/RXD 接口、发送器、接收器与流量控制系统。核心创新是"流量控制子系统"对总线上的 CAN 帧进行解码,检测到 CAN FD(ISO 11898-1 WD / CAN with Flexible Data-Rate v1.0)流量时改变收发器工作状态,使旧式 CAN 控制器不被 CAN FD 快速位流打乱。

## 为什么值得读
- **模拟IC 工程师**:收发器不只是"差分驱动 + 比较器",还承担帧格式感知与状态切换职责;数字控制(边沿检测、定时、模式切换)与模拟前端(TXD 偏置、总线偏置、静音/睡眠阻抗)需协同设计,模式切换时的总线阻抗与漏电是模拟设计要点。
- **嵌入式开发工程师**:理解 CAN FD 流量如何被收发器感知,以及 passive partial networking 的概念来源。

## 核心内容要点
- **解决的问题**:在混合 CAN / CAN FD 网络中,旧式 CAN 控制器遇到 CAN FD 快速位流时可能被误同步、状态被打乱。
- **技术方案**:流量控制子系统解码总线上的 CAN 帧,检测到 CAN FD 流量后改变收发器工作状态——例如把 TXD 通路与总线断开(RXD 仍连),或把 TXD/RXD 全部与总线断开。
- **背景梳理**:专利系统梳理了 CAN FD 的几种演进路线(passive partial networking、stand-alone 控制器、控制器升级等),是理解 CAN FD 收发器架构演进与 partial networking 的必读文件。
- **设计启示**:收发器的状态感知与模式切换涉及模拟前端(总线偏置、静音/睡眠阻抗、漏电)与数字控制(边沿检测、定时、模式机)的协同设计。

## 怎么读
先通读架构图了解收发器各子系统,再重点精读流量控制系统对 CAN FD 帧的检测与状态切换逻辑;对照专利中对 passive partial networking 演进路线的梳理理解设计动机。PDF 免费公开,可直接下载本地阅读。
