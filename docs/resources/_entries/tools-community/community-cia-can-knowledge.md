## 是什么
**CiA CAN Knowledge** 是 CAN in Automation(CiA)官方维护的**免费知识库**,收录成体系的 CAN / CAN FD 原理文章,由标准化组织官方撰写,**权威且成体系,强烈推荐**。

## 为什么值得读
- **模拟IC 工程师**:官方视角的协议与物理层原理文章,比二手资料可靠得多。
- **嵌入式开发工程师**:从标准组织视角理解协议细节,配合工作场景查缺补漏。
- **学生**:一份免费、权威、结构化的 CAN FD 入门与进阶读物。

## 核心内容要点
- **语言/内容类型**:英文;官方知识库文章(免费)。
- **适用场景**:学习——CAN / CAN FD 原理的系统阅读。
- 内容覆盖协议、物理层、拓扑、位定时等主题,与 ISO 标准直接对应。

## 怎么读
按知识库的目录结构顺序通读,先建全局概念,再按需精读与工作相关的主题;可与[资源库 — 标准规范](../../standards.md)对照阅读。
