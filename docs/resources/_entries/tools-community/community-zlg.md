## 是什么
周立功 ZLG(致远电子)是国产 CAN / CAN FD 分析仪与接口产品厂商,官网提供**大量中文应用文档与教学视频**,是中文学习者获取 CAN 资料的便利渠道。

## 为什么值得读
- **模拟IC 工程师**:中文应用文档便于快速理解总线产品用法与常见问题。
- **嵌入式开发工程师**:ZLG 的 USBCAN 等产品与配套工具在国产方案中常用,资料齐全。

## 核心内容要点
- **语言/内容类型**:中文;厂商资料库/教学资源(免费访问)。
- **适用场景**:学习/开发——中文文档、教学视频、产品配套资料。
- **甄别提醒**:SIC 概念较新,中文资料错漏较多;涉及 SIC 参数以 ISO 11898-2:2024 和厂商数据手册为准。

## 怎么读
到官网按产品线(USBCAN / CAN FD 分析仪)浏览应用文档与视频;同时可结合[知乎 / CSDN](community-zhihu-csdn.md)条目中的甄别提醒交叉核对。
