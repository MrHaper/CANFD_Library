## 是什么
**阻抗 / 网络分析仪**是通用射频/阻抗测量仪器,用于测量 CAN 收发器的**输出阻抗**与**回波损耗**——这两项是 SIC 收发器规范(ISO 11898-2:2024 / CiA 601-4)中的关键指标,直接影响振铃抑制与信号质量。

## 为什么值得读
- **模拟IC 工程师**:输出阻抗与回波损耗是 SIC 收发器电气特性的核心验证项,阻抗分析仪是测量这些指标的专用设备。
- **嵌入式开发工程师**:理解网络侧阻抗匹配对振铃与信号完整性的影响。
- **学生**:把"规范里的回波损耗指标"与"实际测量"对应起来,是理解 SIC 价值的一环。

## 核心内容要点
- **用途**:测收发器输出阻抗、回波损耗(SIC 规范关键指标)。
- **免费/付费**:付费(通用仪器,可实验室配备或按需租用/委托测试)。
- **适用场景**:测试——物理层电气特性验证。
- 需与被测件(SIC 收发器/测试板)配合,按规范要求的频率范围与端接条件测量。
