## 是什么
Stack Overflow 上以 **`can` 标签**聚合的问答,覆盖 CAN / CAN FD 的**协议与软件实现问题**(驱动、帧解析、SocketCAN、python-can 等)。

## 为什么值得读
- **模拟IC 工程师**:了解协议实现层面的常见坑与解读。
- **嵌入式开发工程师**:解决驱动、帧格式、工具用法等具体问题时的高质量答案来源。

## 核心内容要点
- **语言/内容类型**:英文;问答社区(免费)。
- **适用场景**:开发/调试——具体技术问题检索。
- 注意:答案质量参差,优先采纳高票、有验证的回答,关键结论仍以标准与厂商文档为准。

## 怎么读
用 `can` 标签按问题描述搜索;遇到 Linux 驱动问题可配合 [SocketCAN](socketcan.md)、[python-can](python-can.md) 条目交叉验证。
