## 是什么
CAN / CAN FD 一致性测试所依据的**标准文档**:**ISO 16845-1 / -2** 定义协议一致性测试方法(参见资源库 01_标准规范分类);物理层 EMC 另见 **IEC 62228-3**(CAN 收发器 EMC 评估,见总 README 勘误补充)。

## 为什么值得读
- **模拟IC 工程师**:一致性测试的"测什么、怎么测"都由标准定义,是自研芯片验证与认证的依据。
- **嵌入式开发工程师**:理解一致性测试覆盖项,在设计早期规避协议层缺陷。

## 核心内容要点
- **用途**:一致性测试依据——协议一致性(ISO 16845-1/-2)与物理层 EMC 评估(IEC 62228-3)。
- **免费/付费**:付费(ISO / IEC 标准文档需购买)。
- **适用场景**:认证/测试——制定测试方案与验收标准的依据。
- 与[一致性测试系统](canfd-conformance-tester.md)、[EMC 测试系统](emc-test-system.md)、[CiA plugfest](certification-cia-plugfest.md)配套。

## 怎么读
先到 ISO 官网获取标准全文(付费),再对照[资源库 — 标准规范](../../standards.md)分类中的标准清单阅读;协议一致性看 ISO 16845,物理层 EMC 看 IEC 62228-3。
