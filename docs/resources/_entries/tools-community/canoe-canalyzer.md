## 是什么
Vector 出品的车载网络开发/测试工具套件,是车载网络行业的**事实标准**。CANalyzer 侧重总线分析与测量, CANoe 侧重总线仿真、测试与自动化执行,两者均支持 CAN / CAN FD(含 SIC 相关分析)、总线仿真与一致性测试脚本。

## 为什么值得读
- **模拟IC 工程师**:了解自研收发器在行业标准测试环境(Vector 工具链)中如何被验证,便于对齐客户端验收流程。
- **嵌入式开发工程师**:用 CANoe 做网络仿真、剩余总线仿真与一致性测试脚本,是车载开发的主流工作方式。

## 核心内容要点
- **免费/付费**:商业付费软件(可向厂商申请试用)。
- **适用场景**:开发/测试——总线仿真、报文分析、一致性测试脚本。
- **OS 支持**:Windows。
- 支持 CAN FD 与 SIC 分析;一致性测试脚本与 CAN FD 一致性测试系统配套使用。

## 怎么读
建议先到官网了解产品定位与试用申请,再结合具体项目学 CANalyzer 的报文分析,进阶到 CANoe 的仿真与测试自动化。
