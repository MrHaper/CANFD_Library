## 是什么
CAN FD **一致性测试系统**(Vector 或第三方实验室提供),依据 **ISO 16845** 系列标准对控制器/收发器执行协议一致性测试;物理层一致性则多用 CiA plugfest 与厂商测试板完成。

## 为什么值得读
- **模拟IC 工程师**:自研 CAN FD 控制器/收发器的协议一致性认证依据,是进入车载市场前的合规关卡。
- **嵌入式开发工程师**:了解一致性测试的范围与流程,便于在设计早期规避协议实现问题。
- **学生**:理解"一致性测试测什么、怎么测",建立车规验证体系认知。

## 核心内容要点
- **用途**:协议一致性测试(依据 ISO 16845);物理层一致性用 CiA plugfest 与厂商测试板。
- **免费/付费**:付费(测试系统/测试服务)。
- **适用场景**:认证/测试——量产前的协议一致性验证。
- 与[一致性测试标准](certification-conformance-standards.md)、[CiA plugfest](certification-cia-plugfest.md)、[第三方实验室](certification-third-party-lab.md)配套。

## 怎么读
先读 ISO 16845 系列标准明确测试范围,再联系 Vector 或第三方实验室安排一致性测试;物理层项可优先参加 CiA plugfest 互操作活动。
