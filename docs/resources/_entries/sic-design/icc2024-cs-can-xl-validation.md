## 是什么
C&S group 在 iCC 2024(国际 CAN 会议)发表的论文,讨论 CAN XL(含 SIC XL 物理层)网络的验证方法与挑战,覆盖一致性测试、网络级互操作验证等视角,是 CAN XL 时代验证方法的参考文献。

## 为什么值得读
- **模拟IC 工程师**:验证环节决定了设计能否最终被系统接受,本文给出 CAN XL 网络验证的方法与关注点,可迁移到 SIC/SIC XL 收发器的验证计划设计。
- 理解一致性测试与网络级验证的分工,有助于在芯片设计阶段就预留可测性设计。

## 核心内容要点
- CAN XL 网络验证的方法与流程。
- 一致性测试视角:与 ISO 11898-2 / CiA 标准测试项的对应。
- 网络级验证:多节点、拓扑、互操作的验证考量。
- 与 SIC / SIC XL 信号改善相关的验证要点。

## 怎么读
配合知识库 [测试篇](../../../knowledge/sic-design/testing.md) 的一致性测试(ISO 16845 / CiA plugfest)与网络级验证章节阅读,理解从芯片级到网络级的验证链条;可衔接 [一致性测试词条](../../../glossary/plugfest.md)。
