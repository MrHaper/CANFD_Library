## 是什么
以工程实例为主线、面向 CAN 系统设计的中文进阶教材。

- **作者**:史久根、张培仁、陈真勇
- **出版社**:国防工业出版社(2004-10)
- **ISBN**:978-7-118-03572-8
- **页数 / 定价**:312 页 / 39 元
- **获取渠道**:京东有售;上海/北京/广州等公共图书馆有馆藏

内容简介:以实际 CAN 控制系统为实例,讲解 CAN 节点硬件开发、上位机接口与驱动、系统调试,并介绍主流 CAN 高层产品与国际研究进展。

## 为什么值得读
- **模拟IC 工程师**:可了解 CAN 节点在真实系统中的调试与故障排查方法,帮助建立「芯片—节点—总线—系统」的完整链路认知,对理解收发器故障模式(如总线短路、节点掉电)在系统层面的表现有参考意义。
- **嵌入式开发工程师**:节点硬件开发与上位机接口/驱动部分是系统联调的实用材料。
- **学生**:通过实例理解 CAN 系统从节点到总线的完整实现。

## 核心内容要点
- CAN 节点硬件开发与实例。
- 上位机接口与驱动、系统调试方法。
- 主流 CAN 高层产品与国际研究进展。

## 怎么读
适合已有 CAN 协议基础后作为进阶参考,重点读节点硬件开发与系统调试章节,建立「芯片—节点—总线—系统」的完整链路认知。
