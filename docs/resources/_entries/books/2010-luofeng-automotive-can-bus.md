## 是什么
面向汽车电子的 CAN 系统级中文教材(进阶)。

- **作者**:罗峰、苏泽才
- **出版社**:电子工业出版社(2010-01)
- **ISBN**:978-7-121-09777-5
- **页数 / 定价**:356 页 / 59 元
- **获取渠道**:京东、当当有售;豆瓣阅读有官方电子版(付费)

内容简介:面向车载应用的 CAN 系统专著,涵盖汽车网络体系结构、CAN 通信原理、带 MSCAN 的飞思卡尔 MCU 编程、XGATE、CAN 收发器、Bootloader、CAN 标定协议以及 CAN 系统设计/仿真/测试全流程。

## 为什么值得读
- **模拟IC 工程师**:把 CAN 放到整车电子电气架构中理解——为何需要容错、为何规定总线拓扑与终端电阻、收发器在节点中的角色;有助于从应用与测试角度反推收发器芯片需要满足的系统级指标(短路保护、共模范围、唤醒能力等)。
- **嵌入式开发工程师**:MSCAN 编程、Bootloader 与 CAN 标定协议部分是车载节点开发的实用参考。
- **学生**:通过整车视角理解 CAN 系统设计/仿真/测试全流程,弥补单看协议书的"只见树木"。

## 核心内容要点
- 汽车网络体系结构与 CAN 在整车架构中的位置。
- CAN 通信原理、带 MSCAN 的飞思卡尔 MCU 编程与 XGATE。
- CAN 收发器、Bootloader、CAN 标定协议。
- CAN 系统设计/仿真/测试全流程。

## 怎么读
系统集成视角的进阶参考(对应 05 学习路径第 4 步)。已有 CAN 协议基础后建议跳读:重点看 CAN 收发器章节与系统设计/仿真/测试部分,从整车应用与测试角度反推收发器需要满足的系统级指标。
