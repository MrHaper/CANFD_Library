00 协议基础 — CAN / CAN FD 协议层

本篇补齐协议层知识,是后续 SIC 物理层内容的基础。内容依据 ISO 11898-1:2024(数据链路层与物理信令,全文见 标准查阅/ISO 11898-1-2024),关键条目标注标准章节号,可对照原文精读。 术语中文译名参考 GB/T 41588 系列(ISO 11898 系列采标)通用译法。

1. CAN 的分层模型(协议与物理层的分工)

CAN 采用 OSI 分层,ISO 11898 系列按层拆分:

层 内容 标准 对芯片的意义
LLC 逻辑链路控制 帧接收过滤、超载通知、恢复管理 ISO 11898-1 协议控制器
MAC 介质访问控制 帧封装/解封装、错误检测、仲裁、应答 ISO 11898-1 协议控制器
PCS 物理编码子层 位编码/解码、位定时、同步(可选 PWM 编码) ISO 11898-1 协议控制器/PHY 接口
PMA 物理介质接入 收发器:驱动、接收、偏置、唤醒(含 SIC) ISO 11898-2 收发器芯片(本专题)
PMD 物理介质相关 连接器、线缆、振铃抑制电路(可选) 应用相关 PCB/线束

关键分工:协议控制器(MCU 内)做 DLL+PCS;收发器芯片做 PMA。收发器设计者需要理解协议层的位定时/采样点要求,因为物理层延迟与对称性直接决定协议能否在高速率下工作(见第 6 节)。

2.2 经典 CAN 数据帧(CBFF/CEFF,§6.6.10)

SOF | 仲裁场(ID28~ID18 + RTR) | 控制场(IDE/r1 + DLC) | 数据场(0~8 B) | CRC(15位+分隔符) | ACK | EOF(7隐性位)
  • SOF:1 个显性位,标志帧起始(总线空闲后);
  • 仲裁场:11 位 ID(CBFF)+ RTR;29 位 ID 时插入 SRR(隐性)与 IDE(隐性)再续 18 位 ID + RTR(CEFF)。RTR:数据帧显性、远程帧隐性;
  • 控制场:IDE/r1 两位显性(CEFF 为 r0) + 4 位 DLC(0~8);
  • 数据场:0~8 字节;
  • CRC 场:15 位 CRC + 1 位 CRC 分隔符(隐性);
  • ACK 场:ACK slot(发送端发隐性,接收端正确接收后拉显性应答)+ ACK 分隔符(隐性);
  • EOF:7 个隐性位;
  • 帧间空间:3 位 intermission(隐性);错误被动节点另加 8 位 suspend transmission(§6.6.7)。

2.3 CAN FD 数据帧(FBFF/FEFF,§6.6.11)

SOF | 仲裁场(ID + RRS) | 控制场(FDF res BRS ESI DLC) | 数据场(0~64 B) | CRC-17/21 | ACK | EOF
  • RRS(替代 RTR):FD 帧恒为显性(无远程帧);SRR/IDE 规则同 CEFF(FEFF 中 IDE 属于仲裁场);
  • FDF(EDL)位:FD 帧为隐性——与经典帧的保留位(显性)冲突解决:同 ID 时经典帧优先于 FD 帧(§6.6.11.2);
  • BRS 位:隐性 → 数据相位切换高速率;显性 → 全程仲裁速率;
  • ESI 位:发送节点错误状态指示(error-active=显性,error-passive=隐性);
  • res 位:保留(显性);
  • 数据场:0~64 字节(DLC 编码:0~8 直映;9~15 映射 12/16/20/24/32/48/64);
  • CRC:数据场 ≤16 字节用 CRC-17,>16 字节用 CRC-21;CRC 包含填充位计数(3 位)与奇偶位(1 位)——这是 CAN FD 能保持与经典 CAN 相同汉明距离的关键(Hartwich 2012 论文,已下载);
  • 其余(ACK/EOF/帧间空间)同经典。

2.4 位填充(stuffing,§6.6.6 相关)

帧类型 填充规则 范围
经典 CAN 5 个连续相同位后插入 1 个反相填充位 SOF 至 CRC 场之前
CAN FD 仲裁相位 同经典(5 位填充) SOF 至 BRS 采样点
CAN FD 数据相位 固定填充:每 4 个位插入 1 个反相填充位 数据场与 CRC 场

填充规则与 CRC 设计是协议层对收发器"位对称性"提出高要求的原因之一——填充位改变了位模式,收发器必须精确复现每个位的宽度(见 01 章 SIC 的 tBit 对称性)。

3. 仲裁机制(§5.3、§6.6.10.2/6.6.11.2)

  • 总线空闲时,任意节点可开始发送;多个节点同时发送时逐位仲裁;
  • 总线上显性(0)覆盖隐性(1):发送节点发出隐性位却采样到显性 → 失去仲裁,立即转为该帧的接收者;
  • 仲裁从 ID 最高位开始,经典帧到 RTR 结束,FD 帧到 FDF 结束;优先级 = ID 数值小者优先;
  • 非破坏性仲裁:胜者继续发送,无需重发,不浪费带宽;
  • 混合格式规则:同基 ID 时 CBFF/FBFF 优先于 CEFF/FEFF(SRR/IDE 隐性);数据帧优先于远程帧(RTR);经典帧优先于 FD 帧(FDF);
  • 仲裁失败的节点在帧间空间后自动重发(重发尝试,§5.14)。

4.2 仲裁相位 vs FD 数据相位(位速率切换)

  • 帧的仲裁相位(SOF 至 BRS 采样点)用标称位时间(如 500 kbps);
  • BRS 为隐性时,从 BRS 采样点起切换数据位时间(如 5 Mbps),直到 CRC 分隔符第一个采样点(§7.3.2);
  • 采样点位置全网一致是网络设计要点;推荐节点时钟 20/40/80 MHz(CAN FD),CAN XL 推荐 160 MHz(§7.3.2);
  • 振荡器容差由 Phase_Seg1/2 与 SJW 决定(§7.3.6)。

4.3 TDC 收发器延迟补偿(§7.3.4)— 与收发器直接相关

  • 为什么需要:FD 数据相位位时间很短(5 Mbps → 200 ns),发射器需在采样点前收到自己发出的位以做位错误检测;但收发器 TXD→总线→RXD 的环回延迟(如 190 ns)可能超过采样点前可用的时间 → 误判位错误;
  • 适用条件:数据相位位时间 ≤1000 ns 时应使用 TDC;协议控制器内部做延迟补偿;
  • 原理:控制器在数据相位发送时,以二次采样点 SSP(Secondary Sample Point)采样自己回读的位,SSP 位置 = 测得环回延迟 + 可编程 TDC 偏移(以 tq 为单位,§7.3.3);
  • 与收发器设计的关系:环回延迟越小、对称性越好,SSP 裕量越大 → SIC 收紧环回延迟到 190 ns 与位宽对称性,正是为了让控制器 TDC 有足够的余量(CiA 601-1 有配套计算)。

4.4 同步(§7.3.5)

  • 硬同步:总线空闲后 SOF 边沿,强制 Sync_Seg 对齐;
  • 再同步:相位误差导致边沿偏离时,通过 SJW 调整 PS1/PS2 长度;

5.1 五类错误检测

错误 检测者 说明
位错误 bit error 发送节点 发送位与采样位不一致(仲裁期间除外)

5.2 错误帧与恢复

  • 检测到错误的节点发送错误帧:6 个显性位(错误被动节点为 6 个隐性位)+ 8 位错误分隔符;
  • 错误帧破坏当前帧,所有节点丢弃该帧;发送节点自动重发;
  • 总线负载最坏情况:错误重发 × 错误帧(叠加)。

1. 为什么需要 SIC:CAN FD 的高速瓶颈

1.1 背景:星型拓扑与 stub 反射

CAN 网络最大的优势是易扩展——往总线上挂节点即可。但网络复杂化后(如星型拓扑),未端接的 stub(短桩线)成为反射源:信号到达 stub 末端阻抗突变点会产生反射,反射波在网络中来回振荡,叠加在有用信号上形成振铃(ringing)。

  • 常规 CAN FD 收发器虽然额定支持 5 Mbit/s,但在真实车载网络中通常只能用到 <2 Mbit/s(SLLA581 明确说明)。
  • 原因是 5 Mbit/s 数据相位位时间仅 200 ns,振铃在采样点前无法衰减干净,导致 RXD 出现毛刺(glitch)。

1.2 振铃造成的直接后果

以 SLLA581 的 Figure 1-1/1-2 为例(波形描述):

  • 总线差分电压 VOD(CANH − CANL)在显性→隐性转换后振荡越过 900 mV(显性阈值)和 500 mV(隐性阈值);
  • 接收器把振铃误判为显性位 → RXD 上出现伪毛刺(spurious glitches);
  • 数据相位速率越高,位时间越短,振铃占位时间的比例越大,误码率越高。

CAN SIC 的目标:在复杂拓扑(星型、多 stub)下把可用数据速率提升到 5 Mbit/s 甚至 8 Mbit/s,且不需要改动网络拓扑或协议层。

2. 振铃的物理机理(设计前必须理解)

2.1 为什么隐性位最脆弱

  • 显性位(dominant):驱动器以低阻输出级强制驱动总线,差分电压约 1.5~3 V(显性),信号受控,不易受反射干扰。
  • 隐性位(recessive):驱动器输出级变为高阻(约 60 kΩ),总线状态由 60 Ω 端接电阻把分布电容放电决定——总线信号本质上是"靠网络自己放电",没有主动驱动。
  • 因此显性→隐性转换是最脆弱的边沿:任何反射都会叠加在这个放电过程上,而放电时间常数(RC)取决于线缆长度、stub、端接。

图 4 星型拓扑与 stub 反射>

2.2 RC 放电与位时间的矛盾

  • 隐性电平恢复速度受限于总线 RC 时间常数;stub 越长、节点越多,等效电容越大,放电越慢。
  • 5 Mbit/s 数据相位位时间 200 ns,而振铃衰减往往需要数百 ns → 在采样点(约 50~80% 位时间处)信号仍可能在 0.5 V 阈值附近振荡。
  • 结论:传统方案只能靠"限制网络规模/拓扑"来保证高速率,而 SIC 通过主动改善信号来打破这个限制。

3. SIC 的定义与三方面改进

3.1 定义与标准归属

CAN SIC 是在 CAN FD 收发器上增加的信号改善能力,通过减小信号振铃提升复杂拓扑下的最大数据速率。 最早标准化于 CiA 601-4(signal improvement 规范,2019 v2.0.0);2023 年 601-4 撤回,内容并入 ISO 11898-2:2024 第三版(参数集 Set A/B/C);2024 版 Annex A 进一步引入 FAST 模式与 CAN XL 兼容。

3.2 改进一:更紧的位时序对称性(timing symmetry)

SIC 收发器的位宽偏差(bit-width deviation)比常规 CAN FD 收紧了约 60 ns(Adamson 2020),这是数据速率上限突破的关键:

参数 符号 CiA 601-4 / ISO 11898-2:2024 Set C ISO 11898-2:2016(常规 CAN FD)
发送隐性位宽偏差 tBit(Bus) −10 ~ +10 ns(速率无关) 2 Mbps:−65 ~ +30 ns;5 Mbps:−45 ~ +10 ns
接收位宽偏差 tBit(RxD) −30 ~ +20 ns 2 Mbps:−100 ~ +50 ns;5 Mbps:−80 ~ +20 ns
接收时序对称性 tREC −20 ~ +15 ns 2 Mbps:−65 ~ +40 ns;5 Mbps:−45 ~ +15 ns
环回延迟 tLoop ≤190 ns(SIC) ≤255 ns(CAN FD)

来源:SLLA581 Table 1-1 与 "Benefits of CAN SIC" 章节。对称性改善使最坏情况采样点碰撞(见 Adamson Figure 3)的理论速率上限从 ~6 Mbps 提升到远超 8 Mbps(仅考虑对称性、点对点)。

3.3 改进二:有源隐性驱动(active recessive)——SIC 的核心机制

SIC 收发器在显性→隐性转换后,不是立刻进入高阻,而是先进入一段有源隐性(active recessive)相位:

  1. 显性相位:输出级低阻(约 50 Ω 量级)强制驱动,总线为显性。
  2. 有源隐性相位(active recessive):转换后,输出阻抗降到约 100 Ω,主动"拉着"总线向隐性放电——反射波遇到低阻看到的是近似匹配阻抗,振铃被大幅衰减;信号被快速拉到 0.5 V 以下。
  3. 被动隐性相位(passive recessive):有源相位结束后,输出阻抗升回约 60 kΩ,回到标准 CAN 的高阻隐性状态(保证多节点共享总线、显性优先级仲裁不受影响)。

3.4 改进三:振铃抑制/阻抗匹配电路

各厂商在有源隐性基础上,还会加专门的振铃抑制电路来加速衰减: - 显性→隐性转换瞬间并联低阻通路加速放电(recessive nulling,TI); - 瞬态触发式阻尼:检测到振铃峰值即导通泄放管(TI); - 阻抗匹配单元 + 分段斜率控制(Microchip); - 前馈式振铃抑制(NXP); - 振荡抑制单元(Bosch)。 (实现细节与专利对照见 02_设计 专题文档。)

4. 系统级概念(理解 SIC 价值的关键)

4.1 Safe Operating Area(安全操作区)与 Allowable Ringing Time

  • Adamson 2017 提出 "Corrected Sample Point",即考虑所有最坏情况不对称后,信号必须保持的安全操作区;
  • 在安全操作区内,信号可以自由振荡,只要在最早隐性采样点前回到 0.5 V 以下——这段允许时间就是 Allowable Ringing Time;
  • SIC 的价值体现在两个层面:收紧对称性(扩大安全区)+ 快速压振铃(尽快进入安全区)。

4.3 采样点选择

  • 2 Mbps:采样点宜靠后(70~80%),给振铃最多衰减时间;
  • 5 Mbps:采样点宜回中(推荐 50% + 1 tq ≈ 55%),为抖动与 PCB 效应留裕量;

4.4 线缆(CiA 601-6)

  • 线缆阻抗应在 110~140 Ω 之间;
  • PVC 绝缘线缆不满足要求(阻抗温度敏感性 + 传播延迟大),会放大振铃;SIC 的紧对称性与快速隐性边沿对劣质线缆有一定补偿,但仍建议温漂实测。

  • 控制输出边沿斜率可降低高频分量 → 减少 EMC 辐射与反射幅度;

3. 振铃抑制电路实现(专利对照)

这是 SIC 设计的"秘密武器",各家实现路线不同,均有专利保护。建议按"先懂物理、再对照电路"的方式阅读下列专利(全部已下载到 专利分类/)。

3.1 TI:Recessive Nulling(隐性抵消)— US9606948B2(已过期,LRN/HRN 模式)

  • 思想:显性→隐性转换瞬间,额外并联一段低阻通路,加速泄放总线分布电容,让差分波形更快衰减到隐性阈值。
  • 实现:主驱动器旁并联 "recessive nulling driver",在转换后选定时长内保持低阻;分两种模式:
  • LRN(light recessive nulling):只影响隐性位起始的一段;
  • HRN(heavy recessive nulling):整个隐性位都保持低阻(含连续隐性位);
  • 混合模式按总线阻抗特征选择 nulling 时长,必须在采样点前终止。
  • 设计启发:nulling 时长可由寄存器编程;终止时刻的时序精度(与采样点错开)是设计重点;额外低阻通路会增加转换瞬间电流,需评估 EMC/共模电流。

图 15 振铃抑制电路原理>

3.2 TI:瞬态触发振铃抑制 — US11310072B2

  • 思想:不靠精确定时,而是检测振铃本身:显性→隐性跳变后,振铃信号经电容耦合到 NMOS 栅极,幅度超过阈值即让管子导通,把振铃能量泄放到 VCC/GND。
  • 实现:驱动器 M1–M6(含高压/负压保护串联管)+ 脉冲发生器(约 200 ns)驱动 recessive nulling 将内部节点拉到 VCM + 电容耦合的振铃检测/阻尼通路;脉冲宽度固定或可编程。
  • 设计启发:"电平检测 + 自动导通阻尼"结构省功耗且对 PVT 鲁棒,不需要精确计时;关键是耦合电容取值(让振铃过阈值但不误触发)与泄放管的尺寸。

3.3 Microchip:阻抗匹配 + 分段斜率 — US11539548B2(权利要求明确标注 CAN SIC)

  • 思想:振铃根源是隐性期阻抗失配 → 在转换期间及之后短时把匹配阻抗接入总线(显性态断开);同时用分段斜率控制减小高频成分。
  • 实现:阻抗匹配单元用 OTA(跨导放大器) 或"背靠背 regulated 晶体管对 + 栅控制电路"实现可控电阻;斜率控制用串联延迟线逐级关断并联电流源/电阻开关。
  • 设计启发:OTA 实现的可控阻抗可在 PVT 下保持振铃抑制性能;阻抗接入/断开的时序与显性态完全隔离,避免影响显性驱动。

3.4 NXP:前馈振铃抑制 — US10020841B2

  • 思想:前馈(feedforward) 方式——在转换发生时主动注入抑制信号,而非等振铃出现再检测,响应更快。
  • 与 TI 的"反馈检测"路线形成对比:前馈依赖精确的转换时刻检测,反馈更鲁棒但略慢。

3.5 Bosch:振荡抑制单元 — US11068429B2(另有申请公开版 US20200364171A1)

  • 针对显性↔隐性位状态切换时的振荡趋势,用振荡抑制单元在切换瞬间改变驱动特性。
  • 设计启发:与仲裁(多节点同时驱动)的兼容性设计——振荡抑制不能破坏显性优先仲裁。

3.6 Elmos:加速状态转换驱动器 — US11048657B2

5.2 Safe Operating Area 仿真 + 台架对照(Adamson 2020 方法论)

  1. 仿真输入:典型(typical)仿真模型 + 最坏情况不对称评估(不叠加所有参数同时最坏,那不符合实际);
  2. 位模式:用 1D1R + 5D1R + 1D1R(1 显性+1 隐性,5 显性+1 隐性,1 显性+1 隐性)——覆盖最长振荡漂移与最短显性后接隐性两种最坏场景;
  3. 判据:隐性位信号在最早采样点前回到 0.5 V 以下;安全操作区边界外设警告区(建议 25 ns 时序缓冲 + 0.05 V 电压缓冲)用于早期预警;
  4. 台架对照:仿真条件与台架测量一致(相同位模式、相同 VCC),便于交叉验证;
  5. 拓扑覆盖:星型、多 stub、长线;可用 Kvaser 2024 iCC 论文的线束布局分析做补充(已下载)。

7. 关键指标设计含义(为什么必须满足)

每个指标不是孤立的数字——它由协议时序、物理传输、EMC、可靠性四类约束推导而来。本节给出 15 个关键指标的物理原因与不满足的后果,是设计规格评审的依据。

7.1 最大额定值 VCAN_H/L −27~+40 V(可选 ±58 V)

  • 要求:一般 −27~+40 V;扩展 −58~+58 V(Table 2);
  • 为什么:车载线束是强干扰环境——感性负载关断(ISO 7637 抛负载)、相邻线缆耦合、地偏移都会在 CANH/CANL 叠加高压瞬态;±58 V 扩展面向 24 V 卡车/48 V 系统,允许更大电源轨与更恶劣瞬态;
  • 不满足的后果:引脚 ESD 结构/闩锁/栅氧击穿,芯片永久损坏——这是可靠性第一道防线。

7.2 隐性输出电平 2.5 V(2.137~2.887 V @60 Ω)

  • 要求:单端 2.5 V 标称(Table 3/Table A.2);
  • 为什么:显性/隐性单端电平决定总线共模电压。全网节点隐性共模一致(≈2.5 V)才能让接收器在宽共模范围内稳定工作;2.5 V 近似电源(VCC=5 V)中点,共模对称性最好,EMC 最优;
  • 不满足的后果:共模偏差 → 接收器共模抑制不足、辐射发射恶化、多节点下隐性被误判。

7.3 显性差分输出 1.5~3.0 V

  • 要求:VDiff 1.5~3.0 V(标称 2.0 V,Table 5);
  • 为什么:信号沿总线传播存在线缆衰减与连接器损耗,接收端 VDiff 必须仍 >0.9 V 显性阈值——1.5 V 下限保证最远节点、最差线缆下仍可靠判显性;3 V 上限限制辐射与功耗;
  • 不满足的后果:下限不足 → 远端节点收不到显性(仲裁错误、丢帧);上限过高 → EMI 超标。

7.4 接收判定 0.9 V / 0.5 V 与迟滞区

  • 要求:显性 >0.9 V、隐性 <0.5 V(Table 7);
  • 为什么:0.5~0.9 V 之间的迟滞区提供噪声容限,防止总线噪声/振铃在阈值附近抖动造成 RXD 毛刺;0.5 V 是"隐性判据"——SIC 把振铃压到 0.5 V 以下正是为此(见 01 章);
  • 不满足的后果:阈值漂移 → 误判;振铃峰值只要高于 0.5 V 就可能被误读为显性位 → 高速率下必然误码。

7.5 接收输入电阻 12~100 kΩ

  • 要求:差分 12~100 kΩ、单端 6~50 kΩ(Table 9);
  • 为什么:每个节点的隐性输入电阻并联在总线上,等效负载 = 60 Ω ∥ (Rin/n);Rin 太小 → 节点数多时总线负载过重、隐性电平被拉低;
  • 不满足的后果:节点容量受限、隐性电平异常、仲裁不可靠。

7.6 未上电漏电流 ±10 µA

  • 要求:±10 µA(Table 11);
  • 为什么:掉电节点必须"透明"——不能影响其他节点通信(总线保持隐性 2.5 V);
  • 不满足的后果:漏电大 → 总线电平被拉偏,整个网络通信失效(单点拖垮全网)。

7.7 驱动对称性 Vsym 0.9~1.1

  • 要求:0.9~1.1(Table 12);
  • 为什么:显性↔隐性切换时共模电压变化幅度小且对称,差分信号中的共模分量(EMI 主要来源)才小——这是无共模扼流圈也能满足 EMC 的关键机制;
  • 不满足的后果:不对称 → 共模发射超标,整车 EMC(如 CISPR 25)无法通过。

7.8 TXD 显性超时 0.8~10 ms

  • 要求:0.8~10 ms(Table 13);
  • 为什么:防止协议控制器故障导致 TXD 持续显性——总线被"拉死",所有节点无法通信;
  • 不满足的后果:单个节点故障即可使全网瘫痪(无超时保护时)。

7.9 环回延迟 ≤190 ns(SIC)

  • 要求:≤190 ns(Table 14,参数集 C);A/B 集 ≤255 ns;
  • 为什么:5 Mbps 数据相位位时间仅 200 ns,发射器需在采样点/SSP 前收到自己回读的位;190 ns 环回 + 控制器 TDC 才能在 200 ns 内完成判定;环回越小,可支持的速率与网络长度越大;
  • 不满足的后果:高速数据相位位错误 → 数据相位速率被限制在 2 Mbps 以下(这正是普通 CAN FD 的瓶颈,见 00 章 TDC)。

7.10 位宽对称性 ΔBit(Bus) ±10 ns / ΔRec −20~+15 ns

  • 要求:Table 17(参数集 C);
  • 为什么:位宽偏差直接挤占采样窗口;全网节点偏差叠加后,采样点必须仍落在位中间;±10 ns 让 5 Mbps(200 ns 位)仍保有足够裕量——对比参数集 A 的 ±65 ns 只能支持 ≤2 Mbps;
  • 不满足的后果:采样点偏移 → 误码;这是 SIC 相比常规 CAN FD 最核心的时序收益(Adamson 2020:收紧 60 ns)。

7.11 有源隐性阻抗 RDIFF_act_rec 75~133 Ω

  • 要求:75~133 Ω(Table 18);
  • 为什么:有源隐性期间驱动阻抗接近总线差分特性阻抗(~120 Ω),反射波到达时被吸收而非反射;75 Ω 下限避免过度加载(与 60 Ω 端接并联),133 Ω 上限保证足够阻尼;
  • 不满足的后果:太低 → 隐性电平被拉低 + 功耗增大;太高 → 振铃压不住,采样点前回不到 0.5 V。

7.12 SIC 窗口 120 / 355 / 530 ns

  • 要求:tact_rec_start ≤120 ns、tact_rec_end ≥355 ns、tpas_rec_start ≤530 ns(Table 18);
  • 为什么:有源隐性必须在转换后立即启动(≤120 ns,振铃刚起就阻尼),持续覆盖整个隐性位(≥355 ns,5 Mbps 位时间 200 ns),并在仲裁相位(1 µs 位)内回到高阻(≤530 ns),保证多节点仲裁时显性仍可覆盖;
  • 不满足的后果:启动晚 → 振铃已形成;结束早 → 振铃未衰减完;结束晚 → 隐性被"强拉",仲裁失效或功耗大。

7.13 唤醒滤波 tFilter(0.15~5 µs)

  • 要求:长 0.5~5 µs / 短 0.15~1.8 µs(Table 20);
  • 为什么:总线噪声/毛刺不能误唤醒节点(静态功耗);但滤波过长唤醒延迟大——折衷值由系统实时性要求决定;
  • 不满足的后果:太短 → 误唤醒耗电;太长 → 唤醒慢,实时性差。

7.14 总线静默超时 tSilence(0.6~1.2 s)

  • 要求:0.6~1.2 s(Table 23);
  • 为什么:总线长时间无活动(如休眠网络)时自动关闭隐性偏置,降低静态电流;0.6 s 下限避免正常通信间隙被误判为静默;
  • 不满足的后果:太短 → 正常通信时误关偏置;太长 → 静态功耗高。

7.15 SOF 前空闲位数 6~10

  • 要求:6~10 个隐性位(Table 21);
  • 为什么:SOF 判定需要连续隐性位确认总线空闲,防止噪声/残留振铃被误认为 SOF;6 下限与 3 位 intermission 兼容;
  • 不满足的后果:下限太少 → 噪声误判 SOF;上限太多 → 总线利用率下降。
