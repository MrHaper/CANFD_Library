## 定义

**时间量子(Time Quantum, TQ)** 是 CAN 位定时的最小时间单位:控制器将系统时钟按预分频系数(BRP)分频得到 `TQ = 预分频系数 × 系统时钟周期`。一个位时间由**整数个 TQ** 组成,每个段都以 TQ 的整数倍配置。

**位时间(Bit Time)** 是总线上一个位的标称持续时间(1/比特率),被划分为四段:**同步段(Sync Seg)→ 传播段(Prop Seg)→ 相位缓冲段 1(PS1)→ 相位缓冲段 2(PS2)**。**采样点(Sample Point)** 位于 PS1 与 PS2 的交界,是节点读取总线电平的时刻。模型由 **ISO 11898-1** 定义。

## 要点

### 位时间四段结构

```
采样点(%) = (Sync Seg + Prop Seg + PS1) / 位时间总 TQ 数 × 100%
```

| 段 | 典型长度 | 作用 |
|---|---|---|
| 同步段(Sync Seg) | 固定 1 TQ | 总线电平跳变应在此发生,是硬同步/重同步的基准 |
| 传播段(Prop Seg) | 视网络延迟 | 吸收信号在总线与收发器上的传播延迟,让"自己发的显性回波"在采样点前稳定 |
| 相位缓冲段 1(PS1) | 可配置 | 可被重同步延长,用于向后调整采样点 |
| 相位缓冲段 2(PS2) | 可配置 | 可被重同步缩短,用于向前调整采样点 |

- 位时间 TQ 数常见为 8~25(视控制器与配置);TQ 越短(预分频越小),段划分越精细,但要求系统时钟频率更高。
- 比特率 = 1 /(位时间)= 1 /(TQ 数 × TQ 时长)。

### 采样点怎么定

- 仲裁相位(经典 CAN 同规则)采样点常见配置在 **70%~87.5%** 附近;
- CAN FD 数据相位通常配置得**更靠后(常见 80%~90% 附近)**,因为高速下 PS1 大、PS2 小,留给重同步与 TDC 后的采样窗口更从容;
- 采样点靠后 = 采样更接近位末,给信号传播、振铃稳定留了更多时间,但重同步调整空间(PS2)变小。
- 具体数值以控制器数据手册与位定时参考表为准,不同控制器推荐值有差异。

### 计算示例

```
系统时钟 80 MHz、仲裁相位 500 kbit/s、位时间 16 TQ:
BRP = 10 → TQ = 125 ns
段分配:Sync 1 + Prop 3 + PS1 8 + PS2 4 = 16 TQ
采样点 = (1 + 3 + 8) / 16 = 75%
```

### CAN FD 数据相位的特殊点

数据相位传播段通常压到 1~2 TQ(环回延迟交给 TDC 补偿),采样点主要由"小传播段 + 大 PS1 + 小 PS2"构成;TDC 使能后,实际采样在**第二采样点(SSP)**进行,不再按固定百分比工作,详见[TDC](tdc.md)知识点。

## 与收发器/控制器设计的关联

- **对控制器(嵌入式)**:TQ 预分频与各段寄存器是位定时配置的全部手段;`ip -details link show can0` 可查看内核实际协商的 `tq/prop-seg/phase-seg1/phase-seg2/sjw` 与采样点,是核对配置的第一现场。仲裁与数据相位两套位时间必须分别配置,全网络节点采样点必须一致(或落在容差内)。
- **对收发器(模拟 IC)**:传播段需要吸收的正是收发器的环回延迟(tTX + tRX)——收发器延迟越小,仲裁相位传播段越短、可支持的拓扑越长;采样点后置对"信号在采样时刻必须稳定"的要求,直接转化为收发器驱动沿整形与振铃抑制的需求,是连接[物理层与SIC](../physical-layer/index.md)分域的桥梁。
