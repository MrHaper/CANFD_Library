## 定义

**相位裕度(Phase Margin)** 是采样点两侧还可容忍的相位偏差总量:粗略地看,总相位裕度 ≈ 相位缓冲段 1 + 相位缓冲段 2 的长度之和(以 TQ 计)。它被总线传播延迟、收发器传播延迟不对称与各节点时钟偏差共同消耗——**"网络能不能跑"的本质问题是:配置完之后相位裕度是否仍为正。**

**同步**是节点把采样点拉回正确位置的机制:**硬同步**在帧起始 SOF 边沿时把所有节点采样点对齐到同步段;**重同步**在帧内检测到电平跳变早于/晚于预期时,通过延长 PS1 或缩短 PS2 微调采样点,每次调整量不超过**重同步跳转宽度(RJW)**。

## 要点

### 相位裕度预算

```
总相位裕度 ≈ PS1 + PS2(以 TQ 计)

被以下项消耗:
· 总线传播延迟:与线长成正比,双绞线约 5~7 ns/m(以线缆特性为准)
· 收发器传播延迟及其不对称性(Δt = tTX − tRX)
· 各节点晶振/时钟偏差随帧长累积的漂移
```

- 仲裁相位:传播段吸收环回延迟,裕度由段配置决定,`2 ×(tTX + tBUS + tRX) ≤ 传播段` 是总线长度的约束来源。
- 数据相位:环回延迟被 TDC 补偿后,剩余的不对称误差、量化误差与振铃抖动仍消耗裕度——因此**收发器传播延迟对称性是数据相位裕度的天花板**,对称性越差,可支持的速率越低。

### 硬同步与重同步

| 机制 | 触发 | 行为 |
|---|---|---|
| 硬同步 | 帧起始 SOF 下降沿 | 所有节点把采样点对齐到同步段,重新开始计时 |
| 重同步 | 帧内边沿早于/晚于预期 | 延长 PS1 或缩短 PS2 微调采样点,调整量 ≤ RJW |

### RJW 的权衡

- RJW 取值通常不大于 PS1 与 PS2 的较小者(以控制器数据手册为准),常见配置 1~4 TQ。
- RJW 越大,容忍晶振偏差与相位漂移的能力越强(有利长帧与高速率);但过大会把采样点推出稳定区,需权衡。
- CAN FD 数据相位因速率切换与 TDC 引入额外相位不确定性,重同步能力对帧可靠性同样重要。

### 常见错误模式

- 采样点早于信号稳定时刻 → 采样到未稳定的电平 → 偶发位错误;
- 传播段过短 → 高延迟网络上采样到回波未稳定 → 位错误;
- 全网络时好时坏 → 各节点采样点不一致,所有节点必须用同一套(或兼容的)位定时。

## 与收发器/控制器设计的关联

- **对控制器(嵌入式)**:相位裕度无法直接"配置",它是段配置、RJW 与网络拓扑共同作用的结果。排查"偶发收不到、莫名错误帧"时,用 `ip -details link show can0` 核对各段 TQ 与采样点,再结合收发器数据手册的延迟参数做预算:裕度为正则配置合理。
- **对收发器(模拟 IC)**:收发器能做的只有一件事——把环回延迟与不对称性做小、做稳。传播延迟对称性(Δt)直接决定数据相位剩余裕度;驱动沿整形与振铃抑制决定采样时刻的信号稳定度。相位裕度分析是把"协议位定时"与"收发器电气参数"连接起来的计算纽带,详见[传播延迟对称性](../../tutorials/09-delay-symmetry.md)与[振铃抑制](../physical-layer/ringing-suppression.md)。
