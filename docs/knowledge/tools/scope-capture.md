## 定义

**示波器抓帧**是物理层验证的核心手段:在总线物理波形层面观察 CAN FD 帧的显性/隐性电平、位定时、振铃与眼图,与协议分析工具的"帧/信号"视图互补。CAN FD 的**一帧两速(BRS)** 让触发、解码与眼图分析都比经典 CAN 更讲究。

## 要点

### 探头与接线

- **用差分探头**跨接 CANH/CANL:单端探头接地参考,会被共模电压淹没,无法正确显示差分波形。
- 测量点尽量靠近被测收发器/总线终端,短接地回路;观察振铃时注意探头寄生电容会改变被测网络特性。

### 触发设置

| 目标 | 触发方式 |
|---|---|
| 抓任意帧 | CAN FD 协议触发(多数高端示波器自带),或 SOF 显性→隐性边沿触发 |
| 抓 BRS 速率切换 | CAN FD 触发 + BRS 条件(数据相位高速率) |
| 抓振铃/边沿 | 显性→隐性下降沿触发,放大观察转换后 200~500 ns |
| 抓错误帧 | 错误帧触发条件(连续显性等),配合解码定位 |

### 协议解码

- 示波器协议解码把波形还原为帧/位:确认 ID、DLC、CRC 与 ACK;经典 vs FD 帧自动判别。
- 解码的价值是**把"波形对不对"和"帧对不对"对上**:波形看起来正常但解码报 CRC 错,指向物理层位损坏或位定时错配。
- 采样率建议满足奈奎斯特之外留足裕量,解码可靠性依赖足够的每 bit 采样点。

### 眼图与模板

- **数据相位眼图**:把数据相位位叠加重合,观察**眼高(电压裕量)、眼宽(时间裕量)**;BRS 后的高速段是眼图分析重点。
- **眼罩模板(mask)**:部分示波器/软件支持按规范(如 ISO 11898-2、厂商参考)定义模板,波形触线即报警——适合收发器对比与一致性预筛。
- 对比测试法:普通 CAN FD(TJA1044)与 SIC(TJA1463)收发器同拓扑下抓数据相位眼图,直观量化 SIC 的振铃抑制收益(见教程[振铃抑制原理与测量](../../tutorials/08-ringing-suppression.md))。

### 常用测量清单

- 显性/隐性差分电平幅度、阈值穿越点;
- 环回延迟量级(发送节点 TxD → 总线回读)与[传播延迟对称性](../../glossary/propagation-delay-symmetry.md)观测;
- 显性→隐性转换后的**振铃峰值幅度与衰减时间**;
- 采样点位置的波形核对(控制器配置的采样点是否落在稳定区域)。

## 与收发器/控制器设计的关联

- **对控制器(嵌入式)**:示波器是位定时/TDC 配置是否生效的"裁判"——采样点位置、错误帧波形、环回延迟测量结果决定配置参数调整方向;解码报错但波形完好时,优先怀疑控制器位定时而非物理层。
- **对收发器(模拟 IC)**:眼图与振铃是收发器输出级、接收比较器指标的波形化表达:数据相位眼高眼宽、转换后振铃量直接对标数据手册的位时序与振铃抑制规格,是流片后表征与竞品对比的标准手段。
