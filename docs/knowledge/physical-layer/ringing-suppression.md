## 定义

**振铃抑制(Ringing Suppression)** 是 CAN SIC 收发器在**显性→隐性转换**后对总线差分/共模振铃进行主动抑制的能力,是 SIC 与普通 CAN FD 收发器在波形层面最直观的区别。ISO 11898-2:2024 对转换后的振铃幅度与持续时间(**振铃抑制窗口**)提出量化要求;要求源头可追溯到 CiA 601-4(SIC 前身规范)与厂商专利。

**机理**:总线物理上是"线缆电感 L + 分布电容 C + 终端电阻 R"构成的 RLC 网络。显性位时输出级低阻强驱动;显性→隐性转换时输出级切到高阻"放手",残留电荷经 L-C-R 欠阻尼放电,形成振荡——即振铃。阻抗失配(桩线、非理想终端、星型节点)会放大它。

## 要点

### 振铃从哪来、为何有害

```
显性位(低阻驱动,总线电荷充足)
  → 显性→隐性转换(输出级切高阻"放手")
  → 残留电荷经 L(线缆电感)· C(分布电容)· R(终端)泄放
  → 阻尼不足 / 阻抗失配 → 欠阻尼 LC 振荡 = 振铃
```

| 危害 | 机制 |
|---|---|
| 误判位 | 振铃峰值越过接收器显性阈值(约 0.7 V 量级,以 ISO 11898-2 为准)→ 隐性位被读成显性位 → 位错误 → 错误帧 |
| TDC 抖动 | 边沿被振铃扰动 → 每次测得的环回延迟不同 → TDC 补偿不准 |
| 限制拓扑 | 振铃限制可容忍的桩线长度、节点数与星型结构——普通 FD 收发器在 5 Mbit/s 基本只能点对点工作的直接原因 |

### SIC 怎么抑制:主动阻尼 + 振铃抑制窗口

- SIC 在显性→隐性转换后的一段时间里不再"完全放手",而是给总线一个**主动阻尼通路**(低阻泄放、受控下拉或切换式终端),把振荡能量快速泄放,把振铃压到接收器阈值之下。
- ISO 11898-2:2024 规定转换后振铃必须在**振铃抑制窗口**内回到阈值以下(幅度与持续时间均有量化要求)。
- 普通 CAN FD 收发器按 ISO 11898-2:2016 设计,对此过程不做主动干预——2 Mbit/s 以内位时间长、采样点后置,振铃来得及衰减;5 Mbit/s(位时间 200 ns)时振铃还没衰减完采样点就到了。

### 两类典型电路方案

| 方案 | 代表专利 | 思路 | 特点 |
|---|---|---|---|
| **前馈开关终端** | NXP [US10020841B2](../../resources/_entries/patents/us10020841b2.md) | 在 TXD 引脚检测显性→隐性边沿,前馈闭合与终端电阻串联的开关,把终端阻抗接入总线一段时间(如位时间的 40%~100%),吸收反射/振铃 | 不需要感知总线波形,抗噪声误触发;开关导通电阻/寄生电容要纳入终端匹配设计 |
| **瞬态触发阻尼** | TI [US11310072B2](../../resources/_entries/patents/us11310072b2.md) | 显性→隐性跳变时脉冲发生器(示例约 200 ns)驱动隐性抵消,同时打开振铃泄放通路:振铃经电容耦合到 NMOS 栅极,过阈值即导通,能量泄放到 VCC/GND | "电平检测 + 自动阻尼",无需精确计时,只需保证振铃峰值不越阈值 |

两条路线回答同一个问题:**转换后那段时间总线不能完全没人管**。

### 测量方法

- 用**差分探头**跨接 CANH/CANL(单端探头会被共模淹没),示波器触发设在**显性→隐性下降沿**,观察转换后 200~500 ns 内的波形。
- 记录:**振铃峰值幅度(mV)**、**衰减到阈值以下的时间(ns)**、**振铃周期**。
- 对比对象:NXP TJA1044(普通 FD,ISO 11898-2:2016)vs NXP TJA1463(SIC,ISO 11898-2:2024),或 TI 对偶器件;测量必须在**数据相位高速率**(如 5 Mbit/s)下进行,配合眼图模板可做定量对比。

## 与收发器/控制器设计的关联

- **对收发器(模拟 IC)**:振铃抑制电路是 SIC 输出级设计的核心模块——在驱动级与终端之间增加阻尼路径,同时保证不干扰其他节点的驱动、不劣化输出阻抗匹配。专利(US10020841B2、US11310072B2)与 DENSO 2014 论文(星型 CAN FD 振铃抑制)是理解电路拓扑的公开素材;开关导通电阻、阻尼窗口时长与 PVT 鲁棒性是设计要点。
- **对控制器(嵌入式)**:振铃抑制由收发器完成,但控制器侧的采样点配置、TDC 使能与拓扑规划(短桩线、正确终端)与振铃共同决定数据相位可靠性——"采样点避开振铃"与"振铃被抑制"是两种互补手段。
