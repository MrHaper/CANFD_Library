## 定义

**回波损耗(Return Loss)** 是收发器总线端输入阻抗与总线特征阻抗(120 Ω 双绞线)匹配程度的度量,定义为入射功率与反射功率之比(以 dB 表示);**数值越大,阻抗匹配越好、反射越少**。CAN FD 高速数据相位尤其关注高数据率相关频率范围内的回波损耗。

**EMC(电磁兼容)** 涵盖**发射(EMI)**与**抗扰度(Immunity)**两个方向:发射是设备产生的非期望电磁辐射,抗扰度是设备在电磁环境中仍能正常工作的能力。收发器级 EMC 的评估标准是 **IEC 62228-3**(CAN 收发器 IC 级 EMC 评估,传导发射 150 kHz–1 GHz 与射频抗扰度);整车发射限值依据 **CISPR 25**。两者是 CISPR 25 在芯片层面的落地测试标准,与 ISO 11898-2:2024 的 EMC 条款配套使用。

## 要点

### 回波损耗

```
回波损耗(dB)= 10 × log10(入射功率 / 反射功率)

RL 越大 → 反射越少 → 阻抗越接近 120 Ω
```

- 阻抗失配产生的反射叠加到原始信号上,造成振铃、眼图收窄与采样错误——回波损耗改善与[振铃抑制](ringing-suppression.md)共同支撑高速数据相位。
- 回波损耗**随频率变化**:高频段更易因封装引脚、片上输入网络的寄生电容/电感劣化,是 SIC 收发器设计难点之一。
- 对设计者而言,封装、引脚与片上输入网络都影响高频回波损耗;规范要求数值以 ISO 11898-2:2024 为准。

### 收发器 EMC 的两条腿

| 方向 | 评估内容 | 主要标准 |
|---|---|---|
| 发射(EMI) | 传导发射(150 kHz–1 GHz)与辐射发射 | IEC 62228-3(IC 级)、CISPR 25(整车限值) |
| 抗扰度(Immunity) | 射频注入/辐射干扰下的失效阈值 | IEC 62228-3(IC 级)、ISO 11452 系列(整车级) |

- **发射来源**:收发器输出沿的高频分量、驱动电流回路辐射——数据相位速率越高,边沿越陡,发射越难压。
- **设计杠杆**:共模扼流圈(CMC,串接在 CANH/CANL 上抑制共模噪声)、受控/整形的输出沿(压摆率折衷)、PCB 布局与屏蔽。
- **压摆率的折衷**:沿越陡,采样时刻信号越"干净"但 EMI 增大;沿越缓,EMI 越小但高速数据相位下边沿占用位时间、来不及稳定。沿整形是 EMC 与时序的核心折衷点。

### 表征流程(IEC 62228-3 思路)

```
按规范搭测试板(去耦 + 共模扼流圈 + 终端)
→ 测传导发射(150 kHz–1 GHz)与射频抗扰度
→ 对照限值/失效阈值判定余量
→ 结果可横向比较不同厂商器件
```

- 设计阶段就应把测试板方案考虑进评估计划,预留去耦与共模扼流圈位置。
- 车规认证链路:收发器芯片级(IEC 62228-3)→ 模块/整车级(CISPR 25 限值、ISO 11452 抗扰度)。

### 与振铃/回波的协同

回波损耗差 → 反射 → 振铃放大;振铃抑制好但回波损耗差,高速边沿的高频成分仍会被反射回来叠加成振铃。SIC 的"回波损耗改善 + 振铃抑制"是配套设计,二者缺一不可。

## 与收发器/控制器设计的关联

- **对收发器(模拟 IC)**:输入网络的阻抗匹配(终端阻抗合成、封装/ESD 结构对高频寄生)、输出级沿整形与共模处理,共同决定回波损耗与 EMC 特性——这是 SIC 收发器表征中直接对标 ISO 11898-2:2024 与 IEC 62228-3 的环节,也是流片后测试与认证的必测项。
- **对控制器(嵌入式)**:控制器不直接参与 EMC 表征,但系统布线(共模扼流圈、PCB 布局、终端位置)决定网络能否通过整车 EMC;高速数据相位下的发射问题常通过降沿(配置斜率控制)与滤波缓解。
