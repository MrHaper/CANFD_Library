    ISO 11898-2:2024 关键参数速查¶

    参数来源:ISO 11898-2:2024 全文(见全文页),表号与条款见各节标注。 数值单位与符号与原文一致;关键参数以官方正式版本为准。

    1. 最大额定值(表 2)¶

    来源:5.3.1 节,表 2(HS-PMA maximum ratings of VCAN_H、VCAN_L and VDiff)。施加到 CAN_H / CAN_L 且不造成损坏的静态电压上下限,VDiff 需保持在自身的最大额定范围内;适用于加电与未加电、TXD 无效与 TXD 变为有效(此时 CAN_H/CAN_L 接固定电压)的情况。

    参数 符号 最小 [V] 最大 [V] 条件
    最大额定值 VDiff -5,0 +10,0 需满足一般或扩展最大额定值之一
    一般最大额定值 VCAN_H、VCAN_L -27,0 +40,0 —
    可选:扩展最大额定值 VCAN_H、VCAN_L -58,0 +58,0 —

    注:VDiff = VCAN_H − VCAN_L(见图 2 测试电路);VDiff 最大额定值不保证 VCAN_H / VCAN_L 的所有组合都合规。

    2. 隐性输出特性(表 3/4,总线偏置激活/未激活)¶

    2.1 总线偏置激活(表 3,5.3.2 节)¶

    参数 符号 最小 [V] 典型 [V] 最大 [V] 条件
    CAN_H 单端输出电压 a VCAN_H +2,0 +2,5 +3,0 RL>1010Ω(未接),C₁=C₂=CRXD=0pF
    CAN_H 单端输出电压 b VCAN_H rec +2,137 +2,5 +2,887 RL=60Ω(±1%),C₁=C₂=CRXD=0pF
    CAN_L 单端输出电压 a VCAN_L +2,0 +2,5 +3,0 RL>1010Ω(未接)
    CAN_L 单端输出电压 b VCAN_L rec +2,137 +2,5 +2,887 RL=60Ω(±1%)
    差分输出电压 VDiff -0,5 0 +0,05 —

    注:表中要求同时成立,并非 VCAN_H 与 VCAN_L 的所有组合都满足 VDiff 定义(原文 NOTE)。

    2.2 总线偏置未激活(表 4,5.3.3 节;偏置何时未激活见 5.5.6)¶

    参数 符号 最小 [V] 典型 [V] 最大 [V] 条件

    CAN_L 单端输出电压 VCAN_L -0,1 0 +0,1 同上
    差分输出电压 VDiff -0,2 0 +0,2 同上

    3. 显性输出特性(表 5,5.3.4 节)¶

    参数 符号 最小 [V] 典型 [V] 最大 [V] 条件
    CAN_H 单端电压 VCAN_H +2,75 +3,5 +4,5 RL=50Ω 至 65Ω
    CAN_L 单端电压 VCAN_L +0,5 +1,5 +2,25 RL=50Ω 至 65Ω
    正常总线负载差分电压 VDiff +1,5 +2,0 +3,0 RL=50Ω 至 65Ω
    仲裁期间有效电阻差分电压 VDiff +1,5 未定义 +5,0 RL=2240Ω(见注)
    可选:扩展总线负载范围差分电压 VDiff +1,4 +2,0 +3,3 RL=45Ω 至 70Ω

    注(原文 NOTE):假设最大 R 为 70Ω,2240Ω 对应 32 节点网络(2240Ω/70Ω=32),即最多 32 个节点同时发送显性时单节点驱动负载变小的情况。测量条件 C₁=C₂=CRXD=0pF。

    5. 动态参数(表 12-14,5.4 节)¶

    5.1 驱动器对称性(表 12,5.4.1 节)¶

    参数 符号 最小 典型 最大 条件
    基于 Vcc 的驱动器对称性 a Vsym_vcc +0,9 +1,0 +1,1 RL=60Ω(±1%),C₁=4,7nF(±5%),C₂=CRXD=0pF
    基于 Vrec 之和的驱动器对称性 b Vsym_vrec +0,9 +1,0 +1,1 同上

    注:a) Vsym_vcc=(VCAN_H+VCAN_L)/Vcc;b) Vsym_vrec=(VCAN_H+VCAN_L)/Vrec_sum,Vrec_sum=VCAN_H_rec+VCAN_L_rec。观测条件:TXD 由方波激励,频率对应实现预期支持的最高位速率、但最高 1 MHz(2 Mbit/s)(正常功耗模式)。

    5.2 可选发送显性超时(表 13,5.4.2 节)¶

    参数 符号 最小 [ms] 最大 [ms]
    发送显性超时 tdom 0,8 10,0

    注:旧实现可接受最小 0,3 ms(脚注 a)。0,8 ms 最小值可容纳:位速率 ≥21,6 kbit/s 时 17 个连续显性位、≥45,8 kbit/s 时 36 个连续显性位(原文 NOTE)。

    5.3 环路延迟(表 14,5.4.3 节)¶

    参数 符号 最小 [ns] 最大 [ns]
    参数集 A 与 B 的环路延迟 a tLoop 未指定 255
    参数集 C 的环路延迟 a tLoop 未指定 190
    参数集 C:TXD 到 CAN_H/CAN_L 传播延迟 tprop(TXD_BUS) 未指定 80
    参数集 C:CAN_H/CAN_L 到 RXD 传播延迟 tprop(BUS_RXD) 未指定 110

    注:a) 从 TXD 输入信号边沿到 RXD 输出同极性下一信号边沿的时间跨度,取两个边沿延迟的最大值。测量条件:RL=60Ω(±1%),C₁=0pF,C₂=100pF(±1%),CRXD=15pF(±1%);TXD 上升/下降时间(10%/90%)小于 10 ns。

    6. 位定时参数集 A/B/C(表 15-18,5.4.3 节)¶

    参数集适用位速率范围(前言):参数集 A = 旧版表 13,位速率 >1 Mbit/s 至 2 Mbit/s;参数集 B = 旧版表 14,位速率 >2 Mbit/s 至 5 Mbit/s;参数集 C 为本版新引入(表 17/18)。

    6.1 数据信号时序要求(表 15/16/17)¶

    参数集 A(表 15):全文页中该表未提取出数值行(仅保留表头与脚注),故此处不列数值;参数集 A 对应位速率 >1 Mbit/s 至 2 Mbit/s,参数为发送隐性位宽变化 t△Bit(Bus)、接收隐性位宽变化 t△Bit(RXD) 与接收时序对称性 t△Rec(定义见下表注),具体数值以官方正式版本为准。

    参数集 B(表 16):

    参数 符号 最小 [ns] 最大 [ns]
    发送隐性位宽变化 t△Bit(Bus) -45 +10
    接收隐性位宽变化 t△Bit(RXD) -80 +20
    接收时序对称性变化 t△Rec -45 +15

    参数集 C(表 17):

    参数 符号 最小 [ns] 最大 [ns]
    发送隐性位宽变化 t△Bit(Bus) -10 +10
    接收隐性位宽变化 t△Bit(RXD) -30 +20
    接收时序对称性变化 t△Rec -20 +15

    注:定义 t△Bit(Bus)=tBit(Bus)−tBit(TXD),t△Bit(RXD)=tBit(RXD)−tBit(TXD),t△Rec=tBit(RXD)−tBit(Bus);表中要求同时成立,并非 t△Bit(Bus) 与 t△Rec 的所有组合都满足 t△Bit(RXD)。测量条件:RL=60Ω(±1%),C₁=0pF,C₂=100pF(±1%),CRXD=15pF(±1%);TXD 上升/下降时间(10%/90%)小于 10 ns。表 16 NOTE:位速率至 1 Mbit/s 时不定义 tBit(Bus) 与 tBit(RXD) 的限值。

    7.10 振铃抑制相关条款与要求¶

    • 定义与原理:SIC = 抑制 MDI 振铃的能力(3.21);SIC 模式期间,在信号改善时间内,线束反射引起的潜在差分扰动被减小(A.1)。
    • 实现参数:振铃抑制通过"主动隐性"驱动实现——主动隐性(active recessive)是以低于标称阻抗、持续特定时长的中间驱动级(3.1),最终回到被动隐性(passive recessive,标称阻抗,3.14)。关键时序与阻抗为表 18 的 tact_rec_start(≤120 ns)、tact_rec_end(≥355 ns)、tpas_rec_start(≤530 ns)与 RDIFF_act_rec(75Ω-133Ω),以及表 A.12 的信号改善时间 tsic(+300/+530 ns)。
    • 选择性唤醒对振铃的容忍(5.5.5.3):接收信号须符合信号形状 A/B;n₁ 个连续显性位(n₁∈{1,2,3,4,5}),tA 0≤tA≤55% 的 tBit,tB 0≤tB≤5% 的 tBit(实现可允许更高最大值);发送器时钟频率偏差容差至少 0,5%。
    • 信息性说明(Annex B.1):实现振铃抑制电路时,差分内部电阻在显性→隐性边沿后的一个位宽区间 [tBit(Bus)] 内典型为 100Ω。
    • 关于回波损耗:本版全文未给出独立的"回波损耗"数值参数表;相关抑制效果通过上列 SIC 时序/阻抗与动态参数体现(条目页简介中的"回波损耗"为对 SIC 特性的概括描述)。
