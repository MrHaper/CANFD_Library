# 学习路线总览

## 这个板块是什么

学习路线是这个知识库的"导览员":按 **模拟IC 工程师 / 嵌入式工程师** 两类读者各规划一条分阶段路径,网站以**模拟IC 设计为主线**(嵌入式为辅助读者)。每条路线回答三个问题:

- **学什么** —— 每阶段的目标与必读资料,全部链接到本网站已建成的资源条目页与术语词条,不跳去外站也能读;
- **怎么学** —— 每阶段的动手任务,以自测清单形式给出,可执行、可勾选;
- **学到什么程度算过** —— 每阶段完成标志,是可验证的标准而不是"读完就好"。

> 与知识库、资源库、教程的关系:本板块负责"按什么顺序学";[知识库](../knowledge/index.md) 负责"某个概念是什么";[资源库](../resources/index.md) 负责"资料去哪找、怎么读";[教程](../tutorials/index.md) 是"跟着做一遍"。三者在每条路线的阶段内交叉互链。

## 两条路线怎么选

按你的身份和最终目标对号入座:模拟IC 工程师走[模拟IC 工程师路线](analog-ic.md)(主线),嵌入式工程师走[嵌入式工程师路线](embedded.md)(辅助);两条路线在关键节点互相指向,可随时切换。

### 🎯 模拟IC 工程师路线

!!! tip "适合谁"
    - 正在或打算做 **CAN FD / CAN SIC 收发器模拟设计**(输出级、接收比较器、振铃抑制电路)的芯片工程师;
    - 需要从"协议 → 物理层 → 芯片电路 → 测试认证"补齐全流程知识,以对标 ISO 11898-2:2024 与竞品手册;
    - 前置基础:模拟电路基本素养(运放、比较器、输出级),不需要先精通嵌入式开发。

- **路线周期**:约 10~20 周集中学习,阶段 3(芯片架构与电路实现)为长期,结合工作持续投入
- **终点能力**:能独立推导 SIC 收发器设计指标(振铃抑制 / 回波损耗 / 传播延迟对称性 / EMC),读懂竞品数据手册与关键专利的电路思路,制定一致性测试计划
- 阶段数:6(建立概念 → 协议与位定时 → 物理层与 SIC 规范(核心)→ 芯片架构与电路实现 → 测试与认证 → 系统集成与量产)
- **[:material-chip: 进入模拟IC 路线](analog-ic.md)**

### ⚙️ 嵌入式工程师路线

!!! abstract "适合谁"
    - 要用 MCU 给产品加上 CAN FD(控制器初始化、驱动、协议栈、调试)的 **嵌入式开发工程师**;
    - 需要把协议帧结构、位定时配置、SocketCAN / can-utils / python-can 等工具链一次学明白;
    - 前置基础:熟悉一种 MCU 开发环境,会 C 语言或 Python。

- **路线周期**:约 8~17 周
- **终点能力**:能在实际硬件上跑通 CAN FD 收发、正确配置采样点与 TDC、用示波器解码抓帧、排查错误帧,并能完成 DBC 与多节点系统搭建
- 阶段数:5(协议基础 → 环境与工具 → 驱动与库 → 位定时与调试 → 应用层与系统)
- **[:material-memory: 进入嵌入式路线](embedded.md)**

## 使用建议

1. **按顺序走,别跳阶段**:两条路线都经过打磨,阶段之间有依赖关系(例如没理解 BRS 时序就学 SIC 振铃抑制会卡壳)。
2. **动手任务一定要做**:勾选清单是验收自己的手段,只读资料不做事,完成标志永远达不成。
3. **善用知识库和词条**:阶段内链接的术语词条([术语表](../glossary/index.md))是即时查漏工具,遇到陌生词先点进去看定义再回头继续。
4. **交叉互链随时可切**:两条路线在关键节点互相指向(如嵌入式线位定时调试与模拟IC 线物理层排查处交叉),不需要"学完一条才能看另一条"。
