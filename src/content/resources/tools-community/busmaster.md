## 是什么
RBEI(ETAS)发起的**开源免费** CAN / CAN FD 分析工具 BusMaster,提供图形化总线视图、报文收发、过滤、日志记录与脚本能力,官方支持以 Windows 平台为主(项目定位跨平台)。

## 为什么值得读
- **模拟IC 工程师**:免费图形化工具,快速查看报文时序与数据场,辅助理解自研收发器行为。
- **嵌入式开发工程师**:零成本调试助手,支持脚本化收发与日志分析。

## 核心内容要点
- **免费/付费**:开源免费。
- **适用场景**:学习/开发——协议帧结构观察、报文收发、日志记录。
- **OS 支持**:Windows(官方主要支持;项目自称跨平台)。
- 支持 CAN FD。

## 怎么读
从 GitHub 下载安装,配一块 USB-CAN 接口卡,打开图形化总线视图即可边发边看帧结构;进阶可看脚本扩展与过滤功能。
