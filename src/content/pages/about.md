# 关于

## 🏗️ 项目背景

本站源于一个真实需求:团队**已流片一颗 CAN FD (SIC) 收发器芯片**。在芯片设计、流片与后续表征认证的过程中,发现"协议 → 物理层 → 收发器设计 → 测试认证"这条全流程的知识散落在付费标准、专利、论文、教材与厂商文档中,缺乏一份系统的、按学习顺序组织的导读。

为此,我们建立了一个全流程学习资料库(2026 年),并在其基础上搭建本站,把收集、核对、勘误过的资料与学习路径整理成可公开访问的知识库——既服务于团队自身持续学习,也希望能帮到同样在做 CAN FD / CAN SIC 的工程师。

## 🎯 站点目标

> **方向调整(2026-08-02 起)**:本站定位收窄为专门面向**模拟 IC 设计工程师**(嵌入式工程师为辅助读者),不再设学生/转行者入口;同时新增"项目实践笔记"子域与"标准查阅"功能,沉淀实际项目经验、提供标准全文站内查阅。

让模拟 IC 设计工程师(兼嵌入式工程师)从这里获得学习、开发、设计 CAN FD 的知识:

- **模拟 IC 设计工程师(主线)**:从协议与物理层规范出发,对标 ISO 11898-2:2024 与竞品手册,补齐收发器架构、电路实现与测试认证的全流程能力;
- **嵌入式工程师(辅助)**:掌握帧协议、位定时配置、SocketCAN / can-utils / python-can 工具链,能在实际硬件上跑通与调试 CAN FD。

站点内容组织为[学习路线](learn/index.md)、[知识库](knowledge/index.md)、[教程](tutorials/index.md)、[资源库](resources/index.md)与[术语表](glossary/index.md)五大板块,互相交叉互链。

## 📚 资料来源与致谢

本站资料主要来自以下渠道,并在此致谢相关组织与作者:

- **标准组织**:CiA(CAN in Automation)公开文档与知识库、ISO(标准全文以官方购买渠道为准)、SAE;
- **芯片厂商公开资料**:NXP、TI、Infineon、onsemi、Microchip、Bosch、Elmos 的数据手册、应用笔记与白皮书(如 TI SLLA581、NXP AH1308);
- **专利**:Google Patents 官方 PDF(US9606948B2、US11539548B2 等 12 篇 SIC / CAN FD 关键专利);
- **开放获取论文**:CiA iCC 会议论文、MDPI / IEICE ELEX / EURASIP 等开放期刊;
- **教材作者**:Lawrenz、饶运涛、Voss 等中英文经典教材作者。

所有条目均标注来源与可获取性(可免费下载 / 官方付费链接),具体见[资源库](resources/index.md)。

- **站点内容许可**:本站原创内容(学习路线、知识库条目、教程、术语释义、勘误记录等)以开放许可形式分享,具体许可证以仓库内声明为准。
- **使用提醒**:引用本站内容请注明出处;转载商业版权资料请遵守其原始版权条款。

## ⚙️ 站点技术说明

- 本站由 **MkDocs Material** 构建(中文界面,支持深浅色主题切换、站内中文搜索、标签索引与 mermaid 图);
- 资源条目以 `docs/resources/_data/*.json` 为数据源,经 `scripts/validate_resources.py` 校验后生成,保证链接与字段一致;
- 内容与数据结构变更通过 GitHub 协作,勘误与贡献流程见[勘误与贡献](contribute.md)。
